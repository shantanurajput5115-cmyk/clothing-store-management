# Atelier — Clothing Store Management

A responsive clothing-store management dashboard built with plain HTML, CSS and JavaScript.

## Run the website
1. Extract the ZIP file.
2. Open `index.html` in a modern browser (Chrome, Edge, Firefox or Safari).
3. No installation, server, or build step is required.

## Features
- Responsive dashboard with revenue, orders, stock and category summaries.
- Product catalogue: add, edit, delete, search and filter products.
- Inventory tracking with low-stock and out-of-stock states.
- Order list with searchable records and editable order statuses.
- Customer directory with search.
- Form validation, duplicate-SKU checks, confirmation prompts and success messages.
- Product records persist in browser `localStorage` after refresh.

## Notes
- The dashboard includes illustrative sample sales, orders and customer data for demonstration.
- Product changes are saved locally in the browser where the website is opened. This is a front-end project; it does not include a shared online database, authentication or real payment processing.
- Clothing photography is loaded from Unsplash, so an internet connection is needed to display the remote photos. If a custom image URL is supplied while adding a product, that image will be used for the product card.
